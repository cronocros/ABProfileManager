# ABProfileManager

월드 오브 워크래프트 Retail용 애드온입니다. 액션바 복구, 전문기술 포인트 점검, 지도 길찾기, BIS 추천 장비, 드랍 아이템 레벨 표, 파티찾기 시즌 최고기록 표시를 한 창과 몇 개의 오버레이로 묶었습니다.

## 시즌 2에서 바뀐 점

- 문장 통화가 **안개문장(Mistcrest)**으로 교체됐습니다. `나의 문장` 패널이 모험가 / 노련가 / 챔피언 / 영웅 / 신화 5등급을 시즌 2 통화 기준으로 표시합니다.
- 신화+ 던전 풀 8종을 시즌 2 기준으로 갱신했습니다: `왕들의 안식처`, `세스랄리스 사원`, `루비 생명의 웅덩이`, `눈부신 골짜기`, `공허흉터 투기장`, `날로라크의 소굴`, `죽음의 골목`, `송곳니의 제단`.
- 드랍 아이템 레벨 표를 시즌 2 값으로 전부 교체했습니다.
  - 신화+: 신화 0 클리어 `292` ~ +12 위대한 금고 `318`
  - 레이드: 일반 `292` / 영웅 `305` / 신화 `318~324`
  - 제작: 기본 `318`, 품질 5단계 `331`
  - 구렁: 1단계 `266` ~ 11단계 `295`, 금고 `279~305` (최고 단계 `11`은 그대로)
  - 등급별 상한: 모험가 `282`, 노련가 `295`, 챔피언 `308`, 영웅 `321`, 신화 `334`
  - 시즌 1에 있던 `탐험가` 트랙은 시즌 2에 없어 표에서 제거했습니다.
- WoW 12.1의 버프 정보 접근 제한에 맞춰 스탯 오버레이를 정리했습니다. 전투 / 레이드 / 쐐기 / 전장 중에도 오류 없이 동작합니다.

## BIS 추천 장비는 시즌 2 기준입니다

BIS 추천 장비 데이터를 **한밤 시즌 2 기준으로 갱신**했습니다. 시즌 2 던전 8종과 맹독 심연 전리품이 반영되며 출처는 공식 한글명으로 표시됩니다.

후보 수는 이전보다 적습니다. 시즌 1에는 넓은 후보 풀을 따로 관리했지만, 시즌 2는 검증된 자료만 사용해 전문화당 슬롯별 대표 후보 위주로 담았습니다. 적지만 지금 시즌에서 실제로 얻을 수 있는 아이템입니다.

다음 두 기능은 아직 동작하지 않습니다.

- 쐐기 아이템의 자동 점수화
- 아이템 미리보기 툴팁의 정확한 시즌 아이템 레벨 표시

시즌 2 미리보기 선택자 정보가 아직 확인되지 않아, 잘못된 아이템 레벨을 보여주는 대신 기능을 꺼 두었습니다. 목록과 순서, 모험 안내서 이동은 정상 동작합니다.

BIS 정보는 참고용이며, 실제 장비는 게임 안에서 직접 확인하는 것을 전제로 합니다. 스탯 우선순위 표는 와우헤드 전문화별 스탯 우선순위 페이지의 시즌 2 값을 기준으로 합니다.

## 주요 기능

**액션바**

- 템플릿 저장, 복제, 비교, 부분 적용, 동기화, 최근 1회 되돌리기

**전문기술**

- 주간 퀘스트 / 논문 / 드랍 / 평판 지식서 / 1회성 보물 자동 추적
- `상세 / 요약 / 최소` 3단 오버레이, 목요일 오전 8시 리셋 잔여 시간 표시
- TomTom 설치 시 미완료 보물 waypoint 선택

**지도**

- 한밤(Midnight) 지도 오버레이 전용 탭
- 포탈 / 시설 / 전문기술 / 평판상인 / 던전·공격대 / 구렁 필터
- 실버문, 영원노래 숲, 하란다르, 보이드스톰 포탈 라벨

**드랍 아이템 레벨 오버레이**

- 던전 / 레이드 / 신화+ / 제작 탭별 표
- `단·난이도 | 클리어 보상 | 드랍 문장 | 위대한 금고` 4열
- 우측 고정 `나의 문장` 패널
- `나의 열쇠` 패널에서 오늘의 풍요 4개, 열쇠 파편, 복원된 열쇠 확인
- 구렁 탭 `보물지도 사용` 행

**BIS 추천 장비 오버레이**

- 40개 전문화 전체, 부위별 `1순위 / 2순위 / 3순위+`
- `쐐기 / 레이드 / 제작 / 티어` 독립 필터
- 캐릭터별·전문화별 즐겨찾기 / 보유 체크, 즐겨찾기 최상단 이동, 보유 아이템 취소선
- 아이템 툴팁, 드랍처·보스 표시, 트랙 색상 요약
- 시즌 불일치 시 위 안내 규칙 적용

**캐릭터 스탯 오버레이**

- `직업 - 특성(아이템 레벨)` 헤더, 치명 / 가속 / 특화 / 유연 표시
- 탱커 방어스탯(회피 / 반격 / 막기) 표시 선택
- 메인 창 `스탯 우선순위 표` 버튼에서 40개 전문화 우선순위 확인

**그 외**

- 파티찾기 신화+ 탭의 시즌 최고기록 아이콘 위에 `평점 + 던전명` 표시
- 퀘스트 정리 (안전 정리 / 남겨둘 퀘스트 / 전체 포기)
- 전투메시지 `위로 / 아래로 / 부채꼴` 모드와 방향성 분산
- 메인 창·툴팁·오버레이 글자 크기를 1pt 단위로 조절
- 첫 설치 언어는 클라이언트 기준. 한국어 클라이언트는 한국어, 그 외는 영어

## 설치

`ABProfileManager` 폴더를 아래 경로에 넣습니다.

```text
World of Warcraft\_retail_\Interface\AddOns\ABProfileManager\
```

확인 파일:

```text
World of Warcraft\_retail_\Interface\AddOns\ABProfileManager\ABProfileManager.toc
```

## 빠른 시작

1. `/abpm` 입력
2. `현재 접속 캐릭터` 탭에서 템플릿 저장
3. `액션바` 탭에서 비교 또는 적용 범위 선택
4. `전문기술` 탭에서 이번 주 포인트 진행 확인
5. `지도` 탭에서 지도 오버레이 조정
6. `편의기능` 탭에서 BIS / 드랍템 / 시즌 최고기록 오버레이 on/off
7. `설정` 탭에서 글자 크기와 전투메시지 모드 조정

탭은 `현재 접속 캐릭터`, `액션바`, `전문기술`, `지도`, `설정`, `퀘스트`, `편의기능` 7개입니다. 설정은 와우 `설정 > 애드온 > ABProfileManager`에서도 열 수 있습니다.

## 현재 제약

- 스탯 우선순위 값은 와우헤드 시즌 2 페이지 기준입니다. 점수화 코어(`v1.7`)는 `12.0.5` 시점 구조를 그대로 씁니다.
- 지도 오버레이의 시즌 2 던전·레이드 입구와 구렁 위치는 클라이언트 API로 런타임 조회합니다. 확인되지 않은 위치는 그리지 않습니다.
- 전문기술 지식은 12.1 신규 평판 서적 11종(`누구나 쉽게 배우는 기술: <직업>`)까지 반영했습니다. 주간 퀘스트와 논문 questID가 12.1에서도 유효한지는 아직 인게임 확인 전입니다.
- 액션바 변경 허용 범위는 `1-132`, `145-180`이고 바 모델은 `1~9번 바`까지입니다. `9번 바`는 비행 중 페이지 전환 바이며, `10~12번` 특수 바는 매핑하지 않습니다.
- 전체 퀘스트 포기는 포기 가능한 퀘스트만 대상으로 합니다.
- 제작 주문, catch-up 같은 일부 전문기술 예외 획득원은 자동 집계하지 않습니다.
- 전투메시지 설정은 기본 WoW 전투메시지 on/off를 대신하지 않습니다.
- `열쇠 파편`은 안전한 itemID가 확정되지 않아 `-`로 표시될 수 있습니다.
- 로컬 배포는 `dist/` ZIP 생성까지만 수행하며 WoW 설치 폴더로 자동 복사하지 않습니다.
