# ABProfileManager v1.13.0 로컬 패치

패치 기준일: `2026-09-04`

이 문서는 로컬 패치 패키지 기준 릴리스 노트입니다.

- 로컬 패키지: `dist/ABProfileManager-v1.13.0.zip`
- 대상 클라이언트: WoW `12.1.0` / TOC `## Interface: 120100` / Midnight 시즌 2
- 원격 GitHub 공개 최신 릴리스: `v1.11.0`

시즌 2 인게임 QA에서 확인된 로드 오류와 오버레이 결함을 고치고, 시즌 2 데이터를 와우헤드/DB2로 재검증하고, 영어 표시 결함을 정리한 패치입니다. 2026-08-29 이후 추가된 항목은 아래 `2026-09-03 추가 수정`에 있습니다.

## 주요 변경

- **로드 오류 수정 (`unfinished string`)**
  `UI/MythicPlusRecordOverlay.lua`의 던전명 문자열이 줄 중간에서 끊겨 있어 파일 전체가
  로드되지 않았습니다. 문자열을 한 줄로 복구하고, 문자열 안에 남아 있던 CR(`0x0d`)까지
  제거해 파일 개행을 LF로 정규화했습니다. 이 오류 때문에 쐐기 기록 오버레이 모듈 전체가
  동작하지 않았습니다.

- **쐐기 기록 오버레이가 표시되지 않던 문제**
  `C_MythicPlus.GetSeasonBestForMap`은 `C_MythicPlus.RequestMapInfo()`가 선행되어야
  값을 돌려줍니다. 애드온은 이 요청을 한 번도 하지 않아 시즌 최고 기록이 항상 `nil`이었고,
  결과적으로 오버레이가 매번 숨겨졌습니다. 데이터 요청(5초 스로틀)과
  `CHALLENGE_MODE_MAPS_UPDATE`, `MYTHIC_PLUS_CURRENT_AFFIX_UPDATE`,
  `CHALLENGE_MODE_COMPLETED` 등 도착 이벤트 구독을 추가하고, 데이터가 늦게 오면 최대 8회까지
  지연 재시도합니다.

- **던전 아이콘 훅 누락 보강**
  `ChallengesDungeonIconMixin`에만 `hooksecurefunc`를 걸면, 훅 등록 이전에 생성된 아이콘
  프레임에는 훅이 걸리지 않습니다. 프레임 인스턴스별 훅을 추가하고, 아이콘 수집 경로도
  `DungeonIcons` / `MapIcons` / `Icons` 필드와 깊이 3 자식 프레임 스캔으로 넓혔습니다.

- **`/abpm debug mplus` 진단 명령 추가**
  설정 상태, 필요한 API 존재 여부, `ChallengesFrame` 표시 여부, 수집된 아이콘 수,
  던전별 `mapID` / 이름 / 최고 레벨 / 점수 / 오버레이 상태를 출력합니다.

- **모험 안내서 자동 이동이 던전·보스까지 열리지 않던 문제**
  레이드 항목은 `instanceID`와 `encounterID` 없이 난이도만 넘겨 항상 안내서만 열렸습니다.
  또한 티어 확인 함수가 던전 목록만 조회해 레이드 `instanceID`는 끝내 찾지 못했습니다.
  던전은 하드코딩된 `instanceID` 표에만 의존해, 표가 실제 클라이언트와 어긋나면 그대로
  실패했습니다.

- **`EJournal` 런타임 인덱스 도입**
  `EJ_SelectTier`, `EJ_GetInstanceByIndex`, `EJ_GetEncounterInfoByIndex`로 티어별 던전과
  레이드를 훑어 이름 기준 인덱스를 만들고 캐시합니다. `Data/BISEncounterJournal.lua`의
  하드코딩 표는 빠른 경로로 남기되, 현재 시즌 티어 스캔에서 확인되지 않으면 런타임 인덱스
  결과를 사용합니다. 레이드는 보스 이름으로 인스턴스를 역추적합니다.

- **한국어 클라이언트 보스명 매칭**
  보스명 후보에 `displaySourceKoKR`, `displaySourceEnUS`, `dungeonEnUS`를 추가했습니다.
  기존에는 영문 보스명만 비교해 한글 이름을 돌려주는 클라이언트에서 매칭이 실패했습니다.

- **드랍템 레벨 정보 창 겹침 수정**
  `content` 프레임이 `TOPLEFT`와 `RIGHT` 두 점만 잡혀 있었습니다. WoW에서 `RIGHT` 앵커는
  가로 위치뿐 아니라 세로 중심까지 고정하므로 content 높이가 `프레임 높이 - 92`로 계산됐고,
  바닥에 붙어야 할 문장·열쇠 스트립이 약 46px 위로 올라와 본문 행과 겹쳤습니다. 모든 탭에서
  같은 증상이 나타난 이유입니다. 상·하단 앵커를 명시하고 `tableArea`와 행 배치의 같은
  과제약도 함께 정리했습니다.

- **전리품 기반 보스 해석**
  `BISCatalog.lua`의 `boss` 필드가 전 행 `nil`이라 정적 데이터만으로는 보스를 알 수 없습니다.
  모험 안내서 전리품 목록(`EJ_SelectInstance` → 전리품 순회)으로 `itemID → (encounterID, 보스명)`
  인덱스를 인스턴스당 1회 스캔해 캐시하고, 출처 라벨을 `던전명 · 보스명`으로 표시합니다.
  해석에 실패하면 기존 표시를 그대로 둡니다.

- **쐐기 오버레이에서 던전명 상시 표시**
  이전에는 시즌 기록이 있을 때만 아이콘에 무엇이든 그렸습니다. 이제 던전명은 항상 표시하고,
  기록이 있으면 `+레벨 점수`를 덧붙입니다.

- **시즌 기록 조회 범위 수정**
  폴백 경로가 `C_MythicPlus.GetRunHistory(false, true)`로 **이번 주** 기록만 조회하고 있었습니다.
  `(true, true)`로 고쳐 시즌 전체를 봅니다. 진단 출력도 `시즌 전체 / 이번 주`를 분리해 보여줍니다.

- **디버그 로그 도배 수정**
  `ChallengesFrame.Update` 훅이 재시도 카운터를 리셋해, 그릴 것이 없을 때 재시도가 끝없이
  반복됐습니다. 리셋을 창 표시와 데이터 도착 이벤트로만 제한하고, 동일 메시지는 10초 안에
  재출력하지 않습니다.

- **오늘의 풍요 상시 표시**
  드랍템 레벨 정보 창 하단 스트립에 오늘의 풍요 구렁 이름을 바로 보여줍니다. 기존에는 마우스
  오버 툴팁에만 있었습니다. 스트립 높이는 글자 높이에 맞춰 동적으로 계산합니다. 이름 조회에
  실패했을 때 `확인 불가`를 캐시에 저장해 영구히 고정되던 문제도 함께 고쳤습니다.

- **본문 글자 확대**
  행 라벨 `11 → 13`, 값 `10 → 12`, 머리글 `9 → 11`. 창 폭 `448 → 472`, 행 높이 `17 → 19`로
  늘리고 열 위치를 재배치했습니다.

- **복사 창 추가**
  `/abpm copy mplus`, `/abpm copy log`로 진단과 로그를 복사 가능한 창에 띄웁니다. 매크로에서
  전역 `ABPMCopy(문자열)`로 임의 스크립트 결과도 넣을 수 있습니다.

- **레이드 모험 안내서 이동 완결**
  인게임 진단으로 타깃 해석(`instanceID=1320`, `encounterID=2883`)은 정상인데 화면이 열리지
  않는다는 것을 확인했습니다. `EJ_IsValidInstanceDifficulty`로 난이도를 검증해 유효한 값으로
  낮추고, `EJ_SelectInstance` + `EncounterJournal_DisplayInstance` 폴백을 추가했습니다.

- **보스 목록 조회 방식 수정**
  `EJ_GetEncounterInfoByIndex`는 인스턴스ID를 인자로 넘겨도 해당 인스턴스가 선택되지 않은
  상태에서는 빈 값을 돌려줍니다. 조회 전 `EJ_SelectInstance`로 선택하고 조회 후 복원합니다.
  레이드 보스 매칭이 계속 실패하던 직접 원인입니다.

- **부정 캐시 제거**
  안내서 데이터가 준비되기 전의 실패를 "확정 실패"로 캐시해 세션 내내 복구되지 않던 경로를
  모두 걷어냈습니다. 레이드 인스턴스 목록이 비어 있으면 실패를 기록하지 않습니다.

- **BIS 1·2순위 표시**
  슬롯마다 후보를 최대 2개까지 보여줍니다. 후보가 하나뿐인 슬롯은 하나만 표시합니다.

- **지도 오버레이 시즌 2 대응**
  구렁과 던전·레이드 입구를 `C_AreaPoiInfo.GetDelvesForMap`,
  `C_EncounterJournal.GetDungeonEntrancesForMap`으로 런타임 조회해 표시합니다. 외부 자료
  좌표를 하드코딩하지 않았고, 확인되지 않은 위치는 그리지 않습니다.

- **전리품 인덱스 영구 캐시**
  `SavedVariables`에 저장합니다. 키는 클라이언트 빌드와 시즌이라 패치나 시즌 교체 시 자동
  폐기됩니다. 두 번째 접속부터는 스캔 없이 보스명이 즉시 표시됩니다. 시즌 API가 아직 `-1`을
  돌려주는 시점에는 캐시를 건드리지 않습니다.

- **사용자 안내서 상태 보존**
  `EnsureTier`가 확장팩 선택을 바꾼 뒤 복원하지 않아, BIS 오버레이를 열면 사용자가 보고 있던
  모험 안내서 확장팩이 튀던 문제를 고쳤습니다.

- **`/abpm copy ej` 진단 추가**
  안내서 API 상태, 티어별 던전·레이드 목록, 레이드 보스 목록, 샘플 해석 결과를 복사 가능한
  창에 출력합니다.

## 2026-09-04 교차 리뷰 반영

- **스탯 우선순위 표 창의 패치 표기 정정**
  제목과 부제가 `패치 12.0.5` 기준이라고 표시했지만 값은 와우헤드 시즌 2 기준입니다.
  두 언어 모두 `한밤 시즌 2` / `와우헤드 시즌 2 기준`으로 고쳤습니다.

- **`/abpm log` 창 프레임 누수**
  호출할 때마다 같은 전역 이름으로 새 프레임을 만들고 있었습니다. 복사 창처럼 한 번만 만들어
  재사용하고 `UISpecialFrames`에 등록해 ESC로 닫히게 했습니다.

- **상태 메시지의 성공·실패 판별이 러시아어에서 동작하지 않던 문제**
  판별 낱말표에 한국어와 영어만 있어 러시아어 메시지는 전부 `안내`로 분류됐습니다.
  실패 6종, 성공 10종의 러시아어 어간을 넣었습니다.

- **`FormatStatusMessage`의 접두 경로 통일**
  러시아어 확장이 이 함수를 덮어쓰면서 접두 9종을 하드코딩하고 `kind == "error"`만 봤습니다.
  실제 분류값은 `failure`라 실패 접두가 붙지 않았습니다. 세 언어가 같은 로케일 키를 쓰도록
  통일하고 `failure`와 `error`를 함께 받습니다.

- **접두 중복 방지 가드가 한 번도 동작하지 않던 문제**
  Lua 패턴의 문자 클래스는 바이트 집합이라 `[●◆▲■]`가 멀티바이트 기호를 잡지 못하고,
  `^(성공|실패|안내):%s`는 Lua에 대안 문법이 없어 리터럴로만 맞습니다. 접두 값과 직접
  대조하는 방식으로 바꿨습니다.

- **채팅 메시지의 `[ABPM]` 중복 표기 제거**
  `Utils.Print`가 이미 애드온 이름을 붙이므로 은행·복사 안내 7종에서 접두를 뺐습니다.

- **매크로 예시가 붙여넣으면 실패하던 문제**
  복사 창 사용법이 `ABPMCopy(내용)` / `ABPMCopy(текст)`였습니다. Lua 식별자는 ASCII만
  받으므로 세 언어를 `ABPMCopy(text)`로 맞추고 안내 문장도 다듬었습니다.

- **BIS 모험 안내서 차단 안내 2종 로케일화**
  전투 중 차단과 시즌 불일치 차단 메시지가 언어 분기 없이 한국어였습니다.

- **그 밖**
  복사 창이 전투 중 입력창 포커스를 가져가지 않게 했고, 언어 판별 헬퍼 세 벌을 공용 함수
  하나로 통일했으며, 전문기술 추적기의 중복·미사용 지역 변수를 정리했습니다.

- **문서 정합성**
  `BISOverlay` top-level local 표기(현재 `195` / 검증기 예산 `198` / Lua 상한 `200`),
  동결 파일 개수, `SeasonGuard` 기준 시즌과 `[S2]` 접두, `baselineItemLevel = 318`,
  preview 검증 범위 `318~334`, PvP 실측값, `sources` 태그 현황을 실제 코드와 맞췄습니다.
  `DOC/SEASON2_HANDOFF.md`의 낡은 해시 목록(존재하지 않는 파일 포함)은 단일 출처 안내로
  교체했습니다.

## 2026-09-03 추가 수정

- **전문기술 12.1 신규 평판 서적 11종 추가**
  `Zul'jarra's Forces` 평판 6단계에서 열리는 `Demystifyin': <직업>` 서적이 빠져 있었습니다.
  11개 직업 전부에 각 10점으로 추가했고, questID는 DB2(`ItemXItemEffect` → `ItemEffect` →
  `SpellEffect`)로 확인했습니다. 직업별 평판 보상 합계가 10점에서 20점으로 늘어납니다.
  한국어 표시는 공식 이름 `누구나 쉽게 배우는 기술: <직업>`입니다.

- **시즌 2 한국어 이름 전수 대조**
  신화+ 던전 8종, 레이드 보스 9종, 티어 세트 13종, 지도 별칭을 DB2 한국어 로케일과 대조했고
  모두 저장소 값과 일치했습니다. 바꾼 것은 없습니다.

- **아이템 레벨 상한 결론**
  `gradeMax.myth = 334`를 유지합니다. 와우헤드 금고 표의 `335`는 셀 정렬이 깨진 페이지이며,
  같은 사이트 레이드 표의 신화 보스 `318 / 321 / 324`가 저장소 랭크 사다리와 정확히 맞습니다.

- **신화+ preview selector 후보 확보**
  시즌 2 Myth 트랙이 시즌 1 그룹 `612`에서 그룹 `618`로 바뀌었고, `+10` 금고가 이 그룹을
  가리키는 것을 DB2에서 확인했습니다. 후보는 `ItemBonusListID = 12849`이며 인게임 확인
  전에는 데이터에 넣지 않습니다. 확인 절차는 `DOC/TODO.md` 5장에 있습니다.

- **스탯 우선순위 전수 재대조**
  와우헤드 전문화별 stat-priority 전용 페이지 40개를 다시 받아 저장소 값과 대조했습니다.
  31개는 이미 일치했고, 복원 주술사만 값이 달라 `치명타 및 극대화 > 가속 = 유연성 > 특화`로
  갱신했습니다. 무법 도적은 저장값이 `가속`을 꼴찌로 두고 있었는데, 구형 개요 페이지 수집기가
  조건이 붙은 1순위 스탯을 버리던 버그의 결과와 같은 형태였습니다. 전용 페이지 목록과
  인게임 확인 항목이 모두 `가속` 1순위여서 `가속 > 치명타 및 극대화 > 유연성 > 특화`로
  정정했습니다. 나머지 수동 확정 7종은 동률 표기만 달라 그대로 유지했습니다.

- **영어 표시 정리**
  애드온 언어를 영어로 바꿔도 한국어가 그대로 나오던 곳을 로케일 키로 옮겼습니다.
  `/abpm help`의 은행 명령 두 줄, `/abpm copy` 창의 제목과 사용법 전체, 로그 창 버튼과
  빈 로그 안내, 진단 실패 안내, 전투부대 은행 채팅 메시지 6종, 템플릿 기본 이름과 복제
  접미사입니다. 키 32종을 영어 / 한국어 / 러시아어 세 언어에 넣었습니다.

- **전문기술 항목 이름이 영어 모드에서도 한국어로 나오던 문제**
  `translateObjectiveName`이 선택된 언어를 보지 않고 항상 한국어 번역표를 적용했습니다.
  한국어일 때만 번역하고 그 외에는 원문을 그대로 씁니다.

- **상태 메시지 접두가 항상 한국어였던 문제**
  `● 안내:` / `● 성공:` / `◆ 실패:` 접두가 언어와 무관하게 붙었습니다. 로케일 키로 바꿨습니다.
  또한 `ABPM_ruRU_Final_v3.lua`가 `FormatStatusMessage`를 덮어쓰면서, 호출부가 `kind`를
  넘기지 않는 9곳 전부가 성공/실패 구분을 잃고 항상 `안내`로 표시되고 있었습니다.
  `kind`가 없을 때 원본 분류 로직에 위임하도록 고쳐 모든 언어에서 구분이 돌아옵니다.

- **문서 낡은 표기 정리**
  버전 `v1.12.0` 표기, BIS 카탈로그 `641`행, `BIS 추천 장비는 시즌 1 기준입니다` 헤딩,

- **월드 이벤트 데이터 결함 기록**
