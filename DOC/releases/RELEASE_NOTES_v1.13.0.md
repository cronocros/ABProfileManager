# ABProfileManager v1.13.0

한밤 시즌 2 `울라텍의 저주` 업데이트입니다. 대상 클라이언트는 WoW `12.1.0`입니다.

시즌에 묶여 있던 데이터를 전부 갱신했습니다. 아이템 레벨, 문장, 신화+ 던전 목록, BIS 추천, 스탯 우선순위, 전문기술 지식, 지도 오버레이가 대상입니다.

## 새로워진 것

**시즌 2 아이템 레벨**

드랍템 레벨 정보 창이 시즌 2 값을 씁니다. 강화 트랙 상한은 모험가 `282`, 노련가 `295`, 챔피언 `308`, 영웅 `321`, 신화 `334`입니다. 시즌 2에는 탐험가 트랙이 없어 해당 줄을 뺐습니다.

**안개문장**

`나의 문장` 패널이 시즌 2 문장 5종을 추적하고 현재 보유량을 보여줍니다.

**시즌 2 신화+ 던전**

송곳니의 제단, 날로라크의 소굴, 죽음의 골목, 눈부신 골짜기, 공허흉터 투기장, 왕들의 안식처, 루비 생명의 웅덩이, 세스랄리스 사원입니다.

**BIS 추천 재작성**

BIS 목록을 시즌 2 기준으로 새로 만들었습니다. 전부 시즌 2 아이템이라 이번 시즌에 얻을 수 없는 항목은 없습니다. 확인된 자료만 써서 이전보다 목록은 짧습니다.

부위마다 최대 3순위까지 보여줍니다. 반지와 장신구는 1순위가 둘이라 4순위까지 나옵니다.

**스탯 우선순위 갱신**

40개 전문화를 시즌 2 기준으로 다시 확인했습니다. 무법 도적과 복원 주술사의 값을 바로잡았습니다.

**전문기술 지식**

12.1에서 추가된 줄자라 부대 평판 서적을 11개 직업 모두 추적합니다. 직업별 평판 보상이 10점에서 20점으로 늘었고, 서적을 사용하면 자동으로 집계됩니다.

**지도 오버레이**

시즌 2 던전, 레이드, 구렁 입구가 세계 지도에 표시됩니다. 시즌 1 지역 지도에서도 보입니다.

## 고친 것

**시즌 최고기록 오버레이**

다시 동작합니다. 던전 찾기 창의 신화+ 탭에 던전 이름이 항상 표시되고, 기록이 있는 던전에는 `+단계 점수`가 함께 나옵니다.

**모험 안내서 이동**

BIS 아이템을 클릭하면 해당 던전이나 레이드의 그 보스까지 안내서가 열립니다. 출처 표기도 `던전명 · 보스명` 형태로 나옵니다. BIS 창을 한 번 연 뒤부터는 다음 접속에서도 보스 이름이 바로 붙습니다.

**드랍템 레벨 정보 창**

하단 문장·열쇠 표시줄이 본문과 겹치던 문제를 모든 탭에서 고쳤습니다. 본문 글자를 키우고 창 폭도 함께 넓혔습니다. 오늘의 풍요 구렁 이름은 마우스를 올리지 않아도 하단에 바로 보입니다.

**툴팁 기준 단계 선택**

BIS 툴팁 헤더에서 기준 단계를 고를 수 있습니다. 신화 1/6, 신화 6/6, 영웅 6/6, 챔피언 6/6 네 가지이며 고른 단계가 `기준:` 줄에 반영됩니다. 제작 아이템은 강화 트랙 대상이 아니라 제작 범위로 표시합니다.

## 언어 표시

애드온 언어를 영어나 러시아어로 두어도 일부 문구가 한국어로 나오던 문제를 고쳤습니다. 이제 선택한 언어를 따릅니다.

- 명령어 도움말, 복사 창, 로그 창
- 전투부대 은행 안내 메시지
- 템플릿 기본 이름
- 전문기술 항목 이름
- 상태 메시지 접두(`안내` / `성공` / `실패`)

상태 메시지가 항상 `안내`로만 나오던 문제도 함께 고쳐서 `성공`과 `실패` 구분이 돌아왔습니다.

## 알려진 한계

- 쐐기 아이템 자동 점수화와 툴팁의 정확한 시즌 아이템 레벨 표시는 꺼져 있습니다. 시즌 2 미리보기에 필요한 값이 아직 확인되지 않았고, 확인되지 않은 값을 쓰면 잘못된 아이템 레벨을 보여주기 때문입니다. 목록과 순서, 툴팁, 모험 안내서 이동은 정상 동작합니다.
- 구렁과 신화+ 아이템 레벨은 공개 자료 기준입니다. 확인한 자료와는 모두 일치하지만 아직 게임 안에서 실측하지는 않았습니다.
- 영웅 던전의 위대한 금고 아이템 레벨은 확인되지 않았습니다.
- BIS 정보는 참고용입니다. 실제 장비는 게임 안에서 직접 확인하시기 바랍니다.

## 설치

압축을 풀어 아래 경로에 폴더가 들어가도록 넣습니다.

```text
World of Warcraft\_retail_\Interface\AddOns\ABProfileManager\
```

게임에서 `/abpm`을 입력하면 창이 열립니다.
