# ABProfileManager 업데이트 내역 (2026-09-04)

버전 `v1.13.0` / 한밤 시즌 2 `Curse of Ula'tek` / 와우 `12.1.0`

이 문서는 2026-09-04에 반영된 변경 중 플레이할 때 실제로 달라지는 것만 담습니다.

## 새로워진 것

**쐐기 아이템 미리보기가 돌아왔습니다**

쐐기 항목에 마우스를 올리면 이제 실제 시즌 2 아이템 레벨과 실제 능력치가 보입니다.
신화 1/6 `318` 단계 기준입니다. 자동 점수화도 다시 켜져서, 쐐기 후보가 실제
능력치 순서로 정렬됩니다.

**더 빠르고 가벼워졌습니다**

- 전투 중 화면 끊김이 줄었습니다. 특히 20인 공격대에서 능치 오버레이가 켜져 있을 때
  체감 차이가 큽니다.
- 오래 접속해 있어도 메모리가 계속 늘지 않습니다. 액션바 고스트 표시, BIS 아이템 정보,
  창 이동 기능을 껐다 켜는 경우가 대상이었습니다.
- 체크박스 하나를 눌렀을 때 보이지 않는 화면까지 다시 그리지 않습니다. 설정 창과
  지도 오버레이, BIS 목록, 전문기술 화면의 반응이 빨라졌습니다.
- 쐐기 미리보기 정보가 접속할 때마다 버려지던 문제를 고쳐, 두 번째 접속부터는
  미리보기가 곧바로 나옵니다.

## 고친 것

**전문기술 주간 퀘스트**

주간 퀘스트 변형 4종(마법부여, 약초채집, 채광, 무두질 각 1종)이 추적 목록에서
빠져 있었습니다. 그 주에 해당 변형이 걸리면 완료로 표시되지 않았습니다. 네 종
모두 들어갔습니다.

**스탯 우선순위 표 제목**

표의 값은 시즌 2 기준인데 제목과 부제가 `패치 12.0.5`로 남아 있었습니다.
`한밤 시즌 2` / `와우헤드 시즌 2 기준`으로 고쳤습니다.

**로그 창**

`/abpm log`를 부를 때마다 새 창이 열리던 것을 하나만 쓰도록 고쳤고, `ESC`로
닫힙니다. 복사 창과 같은 동작입니다.

**복사 창**

- 안내에 적힌 매크로 예시가 `ABPMCopy(내용)`이라 그대로 붙여넣으면 실패했습니다.
  `ABPMCopy(text)`로 고쳤습니다.
- 전투 중에 복사 창이 입력 포커스를 가져가지 않습니다.

**중복 표시 제거**

전투부대 은행과 복사 안내 메시지 7종에 `[ABPM]`이 두 번 나오던 것을 정리했습니다.

**모험 안내서 안내 문구**

BIS 아이템 클릭으로 모험 안내서를 열 수 없을 때 나오는 안내 2종이 언어 설정과
무관하게 한국어로 나왔습니다. 이제 선택한 언어로 나옵니다.

## 영어 / 러시아어

**러시아어 번역이 완성되었습니다**

비어 있던 143개 문장을 모두 채웠습니다. 액션바 결과, 고스트 표시 메시지, 명령어
도움말, 스탯 우선순위 표, BIS 툴팁이 대상입니다.

러시아어에서 `Crit`이 `Critical Strike` 안쪽까지 바꿔버려 글자가 깨지던 문제도
고쳤습니다. 이제 낱말 단위로만 바뀝니다.

**상태 메시지**

러시아어에서는 성공·실패 메시지가 항상 `안내`로 표시됐습니다. 이제 세 언어 모두
`성공` / `실패`가 제대로 붙습니다.

**남은 시간 표시**

`시간` / `분` / `초` 표기가 한국어로 고정돼 있어 영어·러시아어에서도 한국어로
나왔습니다. 언어 설정을 따라갑니다.

## 알려진 한계

- 레이드·티어·제작 아이템의 미리보기 툴팁은 아직 기본 아이템 링크로 표시됩니다.
  정확한 미리보기를 만들 근거를 확인하지 못했고, 확인 없이 넣으면 잘못된 아이템
  레벨이 표시됩니다. 쐐기 미리보기는 확인을 마쳐 정상 동작합니다.
- 구렁과 쐐기 아이템 레벨은 공개 가이드 기준입니다. 확인한 모든 출처와 일치하지만
  인게임 실측은 아직 하지 않았습니다.
- 영웅 던전 위대한 금고 아이템 레벨은 미확인입니다.
- BIS 항목은 참고용입니다. 장비는 인게임에서 다시 확인하세요.
